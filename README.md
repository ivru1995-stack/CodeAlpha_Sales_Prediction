📈 Sales Prediction using Python — CodeAlpha Task 4

A Machine Learning project built with Python, `scikit-learn`, `pandas`, `seaborn`, and `matplotlib` to predict product sales based on advertising expenditures across various media channels.

This repository was created as part of the **Data Science Internship at CodeAlpha**.

---

## 📌 Project Overview

Predicting sales is crucial for businesses to optimize marketing budgets and maximize Return on Investment (ROI). The objective of this project is to build a machine learning regression model that accurately forecasts sales based on advertising spend on TV, Radio, and Newspaper.

### Features (3 Input Variables)
* `TV`: Advertising budget spent on TV (in thousands of dollars).
* `Radio`: Advertising budget spent on Radio (in thousands of dollars).
* `Newspaper`: Advertising budget spent on Newspaper (in thousands of dollars)[cite: 1].

### Target Variable
* `Sales`: Total sales units generated (in thousands of units)[cite: 1].
